# 云阅读 myreader 开源版

自托管电子书书库与在线阅读平台：FastAPI + SQLite，前端原生 HTML/JS 零构建。支持 EPUB/MOBI/AZW3/PDF/TXT/Markdown/DOCX 多格式在线阅读、听书（TTS）、书单分享、会员额度、技术报告投放区自动上架与回收。本包为脱敏开源版：真实域名/IP/口令/品牌均已替换，凭据全部改走环境变量。
